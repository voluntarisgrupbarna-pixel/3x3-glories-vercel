# 3×3 Barna 2026 — Torneig de Bàsquet Westfield Glòries

Web oficial del **[3×3 Barna 2026](https://cbgrupbarna-3x3timechamber.com/3x3-barna)** — el torneig de bàsquet 3×3 FIBA de referència a Barcelona.

🏀 **[cbgrupbarna-3x3timechamber.com](https://cbgrupbarna-3x3timechamber.com)**

## El torneig

El **3×3 Barna** és l'esdeveniment anual organitzat per **CB Grup Barna**, **Time Chamber** i **Eix Clot** al barri del Clot-Glòries de Barcelona. La 4a edició, el **3×3 Barna 2026**, se celebra els dies **6 i 7 de juny de 2026**.

- 📍 **On:** Westfield Glòries · La Nau del Clot · Rambleta del Clot — Barcelona
- 🏆 **Premis:** 2.000€ en metàl·lic (1.000€ Sènior Masc. + 1.000€ Sènior Fem.)
- 🌍 **FIBA oficial:** punts per al rànquing mundial individual
- 👥 **10 categories:** de Premini (8 anys) a Veterans (+35 anys)
- 💶 **Inscripció:** des de 75€ per equip (samarreta oficial inclosa)

## Stack tècnic

- **Framework:** Next.js 14 App Router (TypeScript)
- **Estils:** CSS pur (globals.css)
- **Deploy:** Vercel (auto-deploy des de `main`)
- **SEO:** JSON-LD SportsEvent + FAQPage + BreadcrumbList, sitemap dinàmic, robots.ts, IndexNow

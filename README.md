# 3x3 Westfield Glories

Proyecto Next.js listo para desplegar en Vercel.

## Lo que incluye

- Mapa oscuro real con tiles abiertos de CARTO/OpenStreetMap.
- Ruta animada hasta la zona 3x3.
- Marcador de jugador caminando con balon.
- Botones de transporte: caminando, metro, bus y parking.
- Geolocalizacion del usuario.
- Diseno responsive para movil y desktop.

## Mapa

No necesitas token de Mapbox. El proyecto carga un mapa oscuro abierto, asi que al desplegar en Vercel ya deberia verse directamente.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.
